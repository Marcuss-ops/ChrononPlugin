# Showcase assets

`jerusalem.geojson` is a one-feature extraction from geoBoundaries
`ISR ADM2` (simplified), release commit
`9469f09`, downloaded from:

`https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/ISR/ADM2/geoBoundaries-ISR-ADM2_simplified.geojson`

The source metadata declares **CC0 1.0 Universal** (`boundaryLicense`).
The feature is kept as a demo geometry for the `territory_tactical_fill`
showcase; it is simplified data and is not a legal or authoritative boundary.
